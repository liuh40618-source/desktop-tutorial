# 材料投放目录

把待提交的实体材料放进本目录。**文件必须带前缀**，脚本据此归类：

- `doc-` 开头 → 产品说明书 / 商业计划书（**恰好 1 份**）
- `demo-` 开头 → 产品 Demo（**至少 1 个**）

示例：

```
doc-职途产品说明书.pdf
demo-职途演示视频.mp4
```

## 不要放进来

- 原始工程源码、`node_modules/`、数据库文件 `career.db*`
- 含个人隐私或未脱敏信息的文件（通知要求涉密内容须脱敏）
- 与本次参赛无关的旧版本材料

## 说明

本文件仅用于占位，不参与打包。脚本会跳过所有 `.md` 占位文件之外的内容，
但 `README.md` 自身不会被收进提交包。
