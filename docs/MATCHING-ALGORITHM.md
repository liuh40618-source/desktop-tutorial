# 岗位匹配算法与数据来源

## 当前匹配过程

岗位模板的核心技能构成岗位要求向量，用户勾选的技能构成画像向量。技能向量使用 O*NET 31.0 的元素 ID 作维度；尚未映射的本地技能使用独立的 `local:<skillId>` 维度。余弦相似度作为内置岗位排序的首要指标，O*NET 对齐的维度允许不同中文技能通过共同标准维度产生部分相似性。

对模板岗位的信号检测计算把该岗位 `core` 标为正样本，把其余本地技能标为负样本。输出命中率、误报率、`d′ = Z(hit rate) - Z(false alarm rate)` 和判定准则 `c = -0.5 × [Z(hit rate) + Z(false alarm rate)]`。率采用 0.5 的 log-linear 修正，避免零值产生无穷分数。

## 数据来源和适用范围

- O*NET 数据库 31.0（2026 年 8 月发布）由美国劳工部 O*NET Resource Center 发布，采用 CC BY 4.0。来源：[数据库下载](https://www.onetcenter.org/dl_files/database/db_31_0_excel.zip)、[字段字典](https://www.onetcenter.org/dictionary/31.0/excel/)、[许可](https://www.onetcenter.org/license_db.html)。
- [data/onet-31.0.json](../data/onet-31.0.json) 保存版本、来源、许可和本地技能到 O*NET 元素的交叉映射。40/134 个本地技能有映射；这些语义映射是项目整理结果，不代表 O*NET 对这些中文技能的官方翻译或背书。
- 当前中文岗位名称和核心技能仍来自本地模板。O*NET 的美国职业分类尚未逐岗映射到中文职位；`core` 也不是 O*NET 的职业评级。
- `d′` 和 `c` 目前只反映本地模板标签与用户自述技能的区分，不基于招聘、录用或职业成功的真实正负样本，不能解释为录用概率或模型预测效能。
- 真实 JD 仅给出被识别出的技能，没有可信的非要求技能样本，因此只计算技能相似度/覆盖，不计算信号检测指标。

## 后续升级所需数据

要把 O*NET 职业要求真正用于每个本地岗位，需要维护可审核的本地职位 ↔ O*NET-SOC crosswalk（含匹配置信度和复核来源），并用 O*NET 的职业技能/知识评级生成要求向量。要验证招聘预测能力，则另需有代表性的正负结果样本、明确的标签定义和独立验证集；O*NET 本身不提供录用结果。
